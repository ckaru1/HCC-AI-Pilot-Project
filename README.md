# HCC AI Pilot Project – First Iteration of Proposed AI Levels

## Overview 
This Java program calculates linear regression models for crocodilian data and provides a statistical analysis of that data. This was completed as a solo final project for Heartland Community College's CSCI 130, Fall 2026, under instructor Todd Simeone. It also serves as a pilot test of the draft AI levels proposed by Heartland's AI Committee.

## Highlights
For Step 1, the initial linear model for ages 0-5 fits well, but overpredicts as values grow, since crocodile growth slows with age. All 13 of the regression lines from Step 2 match the AI's independent calculations. Full details can be found in the reports folder.

## AI Levels
- Level 0: Create and complete the assignment with no AI.
- Level 1: Create first, then use AI for feedback.
- Level 2: Create with AI support.
- Level 3: Gather information, then use AI to draft or create.
- Level 4: Co-create with AI throughout the process.
